# 3D-Printing-Calibration-and-Designs

![Build 1](./images/Build%201.jpg)
### Equipment & Materials

- **Printer:** Homers / Tevo Tarantula Pro
- **Slicing software:** Ultimaker Cura
- **3D modelling software:** Blender
- **Printing technology:** FDM (Fused Deposition Modeling)
- **Printing material:** PLA (Polylactic Acid)

All documented prints in this portfolio were produced using PLA. My experience includes configuring slicing settings, selecting infill patterns, using tree supports and preparing multi-part models for printing and assembly.

![Build 2](./images/Build%202.jpg)

3D Printer – Homers / Tevo Tarantula Pro

Printer overview

My primary experience with FDM 3D printing comes from using the Homers / Tevo Tarantula Pro. It is a Cartesian-style printer with similarities to the Creality Ender 3, featuring a triple-fan hotend cooling configuration. Working with this printer provided practical experience with desktop 3D printing hardware, print preparation and the limitations of a less widely supported printer platform.

Mainboard

An overview of the printer's mainboard and electronics. This was part of my hands-on experience with the hardware behind FDM printing, including the components responsible for controlling the printer and its movements.

Predator Sculpture

A detailed Predator sculpture printed using PLA, with an approximate print duration of 14 hours.

This project involved preparing a more complex organic model for printing in Ultimaker Cura and using tree supports to accommodate overhanging geometry. The finished model was documented from both the front and back.

Skills demonstrated: Slicer configuration, support generation, handling complex geometry and longer print jobs.

![Build 5](./images/Build%205.jpg)

Custom GPU Support Stand

An original functional design modelled in Blender and subsequently manufactured using FDM 3D printing.

Unlike the other projects, this was my own design rather than simply printing an existing model. The objective was to create a practical support for a graphics card, combining 3D modelling with a real-world hardware application.

The model was prepared in Cura and printed using PLA with a regular infill pattern.

Skills demonstrated: Blender modelling, functional design, model preparation and practical application of 3D printing.

![Build 6](./images/Build%206.jpg)

Gear Cube

A gear-based geometric puzzle printed using PLA.

This project explored the printing of more intricate geometric shapes and mechanical-looking structures. It provided experience with preparing models containing multiple detailed surfaces and features for FDM printing.

Skills demonstrated: Geometric model printing, slicer configuration and handling detailed shapes.

Multi-part Model Car – 01

A second miniature car following the same five-component construction approach, consisting of four wheels and a separate body.

This project provided another opportunity to work with multi-component models and the practical considerations involved in printing and assembling individual parts.

Skills demonstrated: Component-based printing, assembly and repeatable FDM workflows.
